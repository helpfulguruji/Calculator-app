## App name

## Short description

## Long description
All-in-One Calculator brings the everyday calculations you need into one clean, easy-to-use app. Calculate loans, EMI, SIP, GST, percentages, conversions, age, BMI, dates, fuel cost and more — without creating an account.

### Highlights
- Fast basic calculator
- EMI, SIP, FD and GST calculators
- Length, weight, temperature, area and data conversion
- Age and date difference tools
- BMI and fuel cost calculators
- Word and character counter
- Light, dark and system themes
- Optional haptic feedback
- Privacy-first: calculations are processed on-device
